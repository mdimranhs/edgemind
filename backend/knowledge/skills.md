# Skills

This document is organized by proficiency so EdgeMind can answer questions about capability without sounding like a flat keyword list. The goal is to describe how he uses each technology in practice.

## Expert

React, Next.js, Tailwind CSS, JavaScript, and TypeScript are his core frontend tools. He uses them to build production web apps, App Router-based Next.js projects, and UI systems that are structured enough to maintain over time.

React is the main component model he reaches for when building interactive interfaces. Next.js is the preferred framework when the project needs routing, server rendering, SEO support, or a clean path from product page to application. Tailwind CSS is his preferred styling layer because it keeps implementation fast and keeps the design system close to the markup.

## Advanced

Node.js, Express, NestJS, PostgreSQL, MongoDB, React Native, and Expo sit in the advanced range.

He uses Node.js and Express for straightforward API work and service building. He uses NestJS when the backend needs stronger structure, dependency injection, and a more opinionated architecture.

PostgreSQL is part of his advanced stack because he is comfortable with relational modeling, structured data, and API backends that need integrity and long-term clarity. MongoDB is also familiar to him, especially for applications where the document model better matches the domain or where iteration speed matters more than strict relational design.

React Native and Expo are part of his advanced mobile stack. He uses them for cross-platform app development when sharing logic and speed of delivery matter.

## Intermediate

Python, FastAPI, Hugging Face tooling, AI, retrieval-augmented generation, FAISS, Azure, and Railway are in active use and ongoing growth.

Python and FastAPI are important for backend services, AI utilities, and lightweight APIs. Hugging Face tools, RAG, and FAISS are part of his current AI learning and EdgeMind-related work. Azure and Railway are useful deployment environments he has explored in practical scenarios, especially when moving projects from local development into hosted environments.

## Learning

Docker, VPS operations, CI/CD, and GitHub Actions are in working-knowledge territory but remain active learning areas.

He understands the value of these tools and uses them when the project needs deployment or automation, but he is still deepening his fluency. This matters because EdgeMind should answer in a way that reflects growth rather than pretending every area is equally mature.
