# Projects

This file documents the projects that matter for EdgeMind. Each project section includes the problem it addressed, his responsibilities, the architecture, technologies, challenges, lessons learned, current status, and links when available.

## ExtraMile (E-Commerce)

### Problem

ExtraMile is a full-featured e-commerce platform intended to support product browsing, checkout flows, and secure online shopping.

### Responsibilities

He worked on the frontend implementation and the broader application structure needed to support an e-commerce experience.

### Architecture

The project is built around a Next.js application with an App Router structure and reusable UI patterns. It is designed as a production-oriented storefront rather than a one-page demo.

### Technologies

Next.js, WooCommerce, Tailwind CSS, Context API, and SSLCommerz payment integration.

### Challenges

The main challenge in this type of project is keeping the experience responsive and reliable while dealing with product, cart, and payment complexity.

### Lessons Learned

E-commerce projects reward clear state handling, careful UI flow design, and practical integration discipline.

### Current Status

Private code.

### Links

Demo: https://extramile.vercel.app
